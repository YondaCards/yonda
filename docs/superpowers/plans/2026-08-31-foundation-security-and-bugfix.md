# Foundation: Tooling, Secret Hygiene, Production Trigger Fix — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Get the Yonda Cards Apps Script project under local version control with a
working `clasp` push/pull workflow, remove the hardcoded Telegram bot secret from
source, and fix the production→materials write-off trigger that currently watches
the wrong column.

**Architecture:** No new features here — this hardens the existing Apps Script
project (bound to the "test Yonda фин учет" Google Sheet) so Plans 2 and 3
(inventory tool, sales cart) can be developed and deployed safely with `clasp push`
instead of manual copy-paste into the browser editor.

**Tech Stack:** Google Apps Script (V8 runtime), `@google/clasp` CLI, Node.js
(LTS, for `clasp` only — no application code runs in Node), git.

**Spec:** [docs/superpowers/specs/2026-08-31-inventory-and-sales-tools-design.md](../specs/2026-08-31-inventory-and-sales-tools-design.md)

## Global Constraints

- Sheet names referenced by scripts must match the live spreadsheet exactly:
  `Реестр товаров`, `Реестр материалов`, `Склад материалов`, `Ответы на форму (1)`,
  `Операции`, `Счета`, `Справочники`, `Заказы клиентов`.
- `Реестр товаров` columns (1-based): A=ID, B=Дата, C=Тип записи, D=Товар,
  E=Количество, F=Тип, G=Откуда, H=Куда. Column F, not C, holds values like
  "Производство" / "Продажа" / "Перемещение" / "Возврат" / "Заказ у поставщиков".
- Never commit secrets (API tokens, chat IDs treated as sensitive) to git or
  hardcode them in `.gs` source — use `PropertiesService.getScriptProperties()`.
- All Apps Script changes are pushed via `clasp push`, not pasted manually into
  the browser editor, once Task 1 is complete.

### Task 3: Fix the production→materials write-off trigger

**Files:**
- Modify: `AppScripts/ProductionHandler.js:26-50` (function `onEditProduction`
  — confirmed by pulling the live project with `clasp clone` in Task 1; this
  file, despite its name matching the intent, is where `writeOffMaterials`
  and both `handleProduction`/`onEditProduction` triggers actually live)

**Interfaces:**
- Consumes: `SHEET_GOODS_REGISTRY` constant (already defined at the top of
  this file as `'Реестр товаров'`), `writeOffMaterials(timestamp, product, qty)`
  (already defined later in the same file — unchanged by this task).
- Produces: no new interface — this only fixes which column the existing
  `onEdit` trigger inspects.

**Context:** `onEditProduction` currently checks `e.range.getColumn() !== 3`
(column C, "Тип записи" — always holds "Учёт товаров", never "Производство").
The column that actually receives "Производство" is F ("Тип"), column 6. As
written, manually typing "Производство" into a row's Тип cell never fires the
material write-off.

- [ ] **Step 1: Confirm the bug still reproduces on the live sheet**

⚠️ MANUAL: in "Реестр товаров", find a Товар that has at least one row for it
in "Справочники" columns N/O/P (BOM: product/material/qty-per-unit — check
column N for the product name). In a new blank row, set Товар to that
product, Количество to 1, and set column F ("Тип") to "Производство".
Expected (bug present): nothing happens — no alert, no new rows in
"Реестр материалов".

- [ ] **Step 2: Apply the fix**

In `AppScripts/ProductionHandler.js`, replace:
```javascript
function onEditProduction(e) {
  const sheet = e.source.getActiveSheet();

  if (sheet.getName() !== SHEET_GOODS_REGISTRY) return;

  const col = e.range.getColumn();
  const row = e.range.getRow();

  // Срабатывает только если изменилась колонка C (Тип)
  if (col !== 3) return;
  if (e.value !== 'Производство') return;
```
with:
```javascript
function onEditProduction(e) {
  const sheet = e.source.getActiveSheet();

  if (sheet.getName() !== SHEET_GOODS_REGISTRY) return;

  const TYPE_COLUMN = 6; // F = "Тип" (not C = "Тип записи" — see Foundation plan Task 3)
  const col = e.range.getColumn();
  const row = e.range.getRow();

  // Срабатывает только если изменилась колонка F (Тип)
  if (col !== TYPE_COLUMN) return;
  if (e.value !== 'Производство') return;
```
